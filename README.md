# Introduction
This is a Gym Membership Tracker which let you track, count and organize your people
who are taking paid membership of your gym. This project written in python only without any 
usage of external packages. This project can run in the terminal without any extra setup.

## Features
The features that my programs have are.
- Member management
-- You can add, remove members, along with you can keep additional data like
   age, plan they are enroll.
- Payment management
-- You can enter the name of the member. And the program shows you how much he has to 
   pay according to the gym plan he has enrolled.
- Summary
-- You can also get the summary of how many members there are in the gym. And there name,
   age, plan enrolled, fee they need to pay.
- exit
-- Once, you done with your job. You can exit the program.
