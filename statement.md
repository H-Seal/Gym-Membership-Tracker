# Gym Membership Management System
## Problem Statement
Manual management of the gym members can be troublesome in keeping the
details about the members, membership period, and charges.
This project is a simple Gym Membership Management System made using the
Python programming language.
## Features
- Adding gym members
- Storing details like name and age of the members
- Choosing membership period
- Calculating membership charges
- Showing gym summary
- Showing total expected charges
- Exiting the program
## Objective
The objective of this project is to develop a simple system that will manage
the gym members' information using the basics of Python.
